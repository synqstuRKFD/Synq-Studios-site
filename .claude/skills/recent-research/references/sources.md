# Where to look first (primary sources by topic)

Verify these still exist and are current when you use them; URLs change.

| Topic | Primary sources | Good secondary |
|---|---|---|
| AI tools & models | Vendor changelogs/release notes and official blogs (Anthropic, OpenAI, Google, Meta, Mistral), model pages, pricing pages | Hacker News, The Verge / TechCrunch, Simon Willison's blog |
| Claude Code / Claude skills | docs.claude.com / code.claude.com docs, Anthropic news, `anthropics` GitHub org release notes | Community repos (check stars + last commit) |
| Coding frameworks | GitHub Releases + CHANGELOG of the project, official blog, npm/PyPI version pages | State of JS/HTML surveys (note survey date), framework Discord/forum |
| Software updates | Vendor release notes, security advisories (GitHub Security Advisories, CVE/NVD) | |
| Roblox development | create.roblox.com docs + "Release notes", Roblox DevForum "Announcements" category, Roblox Creator Roadmap, Roblox newsroom | DevForum community posts, Roblox charts (Discover page), third-party trackers (label as third-party) |
| Business opportunities | Government statistics (Census, BLS, SBA), company filings, marketplace data you can see directly (Etsy/Fiverr/Upwork listings, app store charts) | Trade press, Google Trends (relative interest only — not volume) |
| Digital marketing / social | Platform official newsroom/blogs and help centers (Meta, TikTok, YouTube, Google Search Central) | Industry newsletters; label vendor "studies" as marketing material |
| Monetization / payments | Stripe, Square, PayPal, Apple/Google developer policy pages and changelogs | |
| Web & app development | MDN, web.dev, caniuse.com, browser release notes (Chrome, Safari, Firefox), framework docs | |

## Red flags

- No date, or "updated" date with no change history
- AI-generated listicles citing no primary source
- Statistics without methodology or sample size
- Vendor surveys promoting the vendor's own product
- Screenshots of claims instead of links
